# Support

Start with [Mornye Support](https://mornye.com/support.html) or the [README FAQ](README.md#faq).

## Report a bug

Open an issue using the Bug report template. Include:

- Mornye version and build, shown in Settings.
- Device model and operating-system version.
- Steps to reproduce, expected behavior and actual behavior.
- Whether it happens consistently, and any workaround you found.
- For audio problems: file extension, codec, sample rate, bit depth if applicable, and local/AirPlay/Cast output.
- For layout problems: light/dark/system appearance and whether the player is expanded or compact.

A short screenshot or recording is helpful. Remove names, paths, account details and other private information first. Do not upload your entire library, private audio files, credentials or unredacted diagnostic archives. A small self-created audio example can be shared if needed later.

## Common checks

**A song will not import:** make sure the file is available locally and readable. Note the exact error. See the [supported audio table](README.md#supported-audio).

**New files are missing:** open Library Settings and scan the selected source folder again. Refresh Songs only rereads metadata from copies already imported into Mornye.

**A folder is unavailable:** select it again in Library Settings. Disconnecting or changing the source folder keeps music already imported.

**Removed songs return:** scanning a source folder can reimport songs still present there. Disconnect the folder if you no longer want to scan it.

**Output quality differs from the source:** check Audio Quality in Now Playing. The system and connected audio device determine the final output format.

**Cast is unreliable:** keep Mornye open, allow local-network access and use a receiver on the same network. Receiver compatibility is still being tested.

## Private support

Email [zarzet@mornye.com](mailto:zarzet@mornye.com). Only send information you intend to share. Potential security vulnerabilities belong in a private report, as described in [SECURITY.md](SECURITY.md).

Support is handled by the maintainer; response times are not guaranteed.
