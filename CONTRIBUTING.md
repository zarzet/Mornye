# Contributing

Help improve Mornye by reporting bugs, suggesting features, and making the documentation clearer.

## Useful contributions

- Reproducible bug reports using the issue template.
- Feature suggestions explaining the problem and how a change would help.
- Corrections to the README, changelog or support instructions.
- Clearer wording, accessible image descriptions and broken-link fixes.

Search existing issues before opening another report. Keep each issue focused on one problem. Be considerate of other users and the maintainer.

## Documentation pull requests

1. Fork this public repository and create a branch.
2. Make a focused documentation change.
3. Check Markdown rendering, relative links and image alternatives.
4. Open a pull request explaining what changed and why.

Keep changes focused on documentation, and leave personal information out of screenshots and logs. Release dates, supported platforms, and download links should match official announcements.

Please discuss large documentation reorganizations first. Translation infrastructure is not available yet; do not assume the app supports a language merely because a document has been translated.
