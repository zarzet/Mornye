# Security reports

Please report suspected security vulnerabilities privately to **[zarzet@mornye.com](mailto:zarzet@mornye.com)** with the subject **Mornye security report**.

Include the affected version, platform, a description of the issue and reproduction steps. Share only the minimum evidence needed. Do not post credentials, private music, personal library data or exploit details in a public issue.

Mornye 0.1 is in development. There is no published security-support window, response-time guarantee or bug-bounty program. The maintainer will review reports and coordinate follow-up directly.
